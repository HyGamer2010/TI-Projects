# TI-Projects
This will be where my various calculator projects are stored. Do keep in mind that I only have a TI-84 EVO, so I develop with that in mind first and cannot personally test whether my PLUS CE versions work. There are 2 main ways I tend to run the files:
## Method 1a: Send to TI-84 EVO

### Step 1

Plug your calculator into your computer. You should see a popup that looks something like this: 
<img width="434" height="94" alt="image" src="https://github.com/user-attachments/assets/30e31e88-0f6f-4edb-8bff-aa0a0b7a8bcd" />

If not, go to <a href = "https://connectevo.ti.com/ticevo/en/">TI Connect Evo<a/> and continue from there.

### Step 2

Click "CONNECT TO CALCULATOR" and select your calculator from the dropdown.

<img width="559" height="533" alt="image" src="https://github.com/user-attachments/assets/055e6ef0-58bd-4080-9ef2-b92a54f40e18" />

### Step 3

Click "SEND FILES," then "SEND TO CALCULATOR," then select a program of your choice where it is located on your drive. Just make sure to not upload files like "sprpacker.py" or any of the init.py programs, as they won't function on the calculator.

<img width="746" height="575" alt="image" src="https://github.com/user-attachments/assets/c2275411-8550-49fd-b5fc-aea41c30c62f" />

## Method 1b: Send to TI-84 Plus CE

### Step 1

Install the <a href = "https://education.ti.com/en/software/details/en/CA9C74CAD02440A69FDC7189D7E1B6C2/swticonnectcesoftware">TI Connect CE software<a/> and get the version for your computer

### Step 2

Plug in your calculator, select it on the side, and click the button with an arrow pointing to the calculator.

### Step 3

Select a program of your choice where it is located on your drive. Just make sure to not upload files like "sprpacker.py" or any of the init.py programs, as they won't function on the calculator.

<img width="746" height="575" alt="image" src="https://github.com/user-attachments/assets/c2275411-8550-49fd-b5fc-aea41c30c62f" />

## Method 2: Run on computer using mock libraries (Windows)

### Step 1

Download my <a href = "https://github.com/HyGamer2010/TI-libs">TI-84 mock libraries<a/> and follow the installation instructions.

### Step 2

Run any of the init.py functions found by the program either by opening a command prompt in the folder:
